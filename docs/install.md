# Установка бота отбора волонтёров

Инструкция для сотрудника музея, который будет ставить и обслуживать систему. Программировать не нужно:
всё запускается готовыми командами, их достаточно скопировать.

Что получится в итоге:

- **бот в сообществе ВКонтакте** — проводит кандидата по анкете, задаёт уточняющие вопросы и присылает
  кураторам карточку каждой анкеты, а через четыре месяца опрашивает волонтёров, которых взяли в команду;
- **дашборд кураторов** — рейтинг кандидатов, карточки, решения, выгрузка в Excel, раздел «Волонтёры»;
- **резервные копии** — раз в сутки, последние две недели.

## 1. Что понадобится

| Что | Где взять |
|---|---|
| Компьютер или сервер, который работает круглосуточно | Подойдёт любой облачный сервер с 1 ГБ памяти и 10 ГБ диска (Linux, например Ubuntu 22.04) или офисный компьютер с Windows 10/11 |
| Сообщество ВКонтакте музея или программы | Нужны права администратора |
| Ключ GigaChat | developers.sber.ru → GigaChat API → «Ключ авторизации». Без ключа бот тоже работает, но без уточняющих вопросов и оценки открытых ответов |
| Беседа кураторов во ВКонтакте | Туда бот будет присылать карточки анкет и сигналы о недовольных волонтёрах |

## 2. Настройка сообщества ВКонтакте (10 минут)

1. Управление сообществом → **Сообщения** → включить. Там же → **Настройки для бота** → включить
   «Возможности ботов» и разрешить добавлять сообщество в беседы.
2. Управление → **Работа с API** → **Ключи доступа** → «Создать ключ», отметить «Сообщения сообщества»
   и «Управление сообществом». Скопировать ключ — это `VK_GROUP_TOKEN`.
3. Там же → **Long Poll API** → включить, версия 5.199; во вкладке «Типы событий» отметить «Входящее сообщение».
4. Добавить сообщество в беседу кураторов. Номер беседы узнаем после запуска (шаг 4).

## 3. Установка

### Сервер с Linux

```bash
curl -fsSL https://get.docker.com | sh
git clone https://github.com/beautiful-cookie/gim-volunteer-bot.git
cd gim-volunteer-bot
cp .env.example .env
nano .env
```

### Компьютер с Windows

1. Установить [Docker Desktop](https://www.docker.com/products/docker-desktop/) и запустить его.
2. Скачать проект: на странице репозитория кнопка **Code → Download ZIP**, распаковать, например, в `C:\gim-bot`.
   **В пути к папке не должно быть русских букв и пробелов** (не «Рабочий стол\Бот»): Docker с ними не собирает проект.
3. В папке проекта скопировать файл `.env.example` в `.env` и открыть его в Блокноте.
4. Команды ниже выполнять в PowerShell из папки проекта (`cd C:\gim-bot`).

### Что вписать в .env

| Строка | Значение |
|---|---|
| `VK_GROUP_TOKEN` | ключ сообщества из шага 2 |
| `GIGACHAT_CREDENTIALS` | ключ авторизации GigaChat |
| `GIGACHAT_SCOPE` | `GIGACHAT_API_PERS` для ключа физлица, `GIGACHAT_API_B2B` для юрлица |
| `DASHBOARD_PASSWORD` | пароль, по которому кураторы входят в дашборд |
| `VK_CURATOR_PEER_ID` | пока оставить пустым — заполним на шаге 4 |

Остальные строки можно не трогать. Файл `.env` никому не пересылайте: в нём ключи доступа.

## 4. Первый запуск

```bash
docker compose run --rm bot python scripts/check_setup.py
```

Скрипт проверит ключи и подскажет, что исправить (✓ — в порядке, ! — желательно поправить, ✗ — обязательно).
Когда ошибок ✗ нет:

```bash
docker compose up -d --build
```

Первый раз сборка занимает 3–5 минут. Дальше:

1. Напишите в беседе кураторов `/id` — бот ответит строкой `VK_CURATOR_PEER_ID=…`. Впишите её в `.env`
   и выполните `docker compose up -d`, чтобы бот перечитал настройки.
2. Напишите сообществу в личные сообщения «Начать» — должна начаться анкета.
3. Откройте дашборд: на этом же компьютере — http://localhost:8501.

### Посмотреть систему до настройки ВКонтакте

Демонстрация на вымышленных кандидатах — ключи для неё не нужны, достаточно скопировать `.env.example` в `.env`:

```bash
docker compose --profile demo up -d --build demo
```

Дашборд с 28 вымышленными кандидатами, решениями кураторов, опросом волонтёров и историей модели
откроется на http://localhost:8502. Настоящие анкеты демонстрация не трогает: у неё своя база `data/demo.sqlite3`.
Остановить: `docker compose --profile demo stop demo`.

## 5. Дашборд для кураторов из любого места

По умолчанию дашборд открывается только на том компьютере, где запущен, — так анкеты не видны из интернета.
Чтобы кураторы открывали его из дома, нужен адрес (домен или поддомен музея, например `volunteers.shm.ru`),
который указывает на IP сервера. Попросите об этом администратора сайта, затем:

1. В `.env` впишите `DASHBOARD_DOMAIN=volunteers.shm.ru` и обязательно задайте `DASHBOARD_PASSWORD`.
2. Запустите:

   ```bash
   docker compose --profile https up -d
   ```

Сертификат HTTPS выпустится сам за минуту. Дашборд будет по адресу `https://volunteers.shm.ru`.

## 6. Обычная работа

| Задача | Команда |
|---|---|
| Посмотреть, что делает бот | `docker compose logs -f bot` (выход — Ctrl+C) |
| Перезапустить всё | `docker compose restart` |
| Остановить | `docker compose down` |
| Обновить до новой версии | `git pull`, затем `docker compose up -d --build` (на Windows — заново скачать ZIP, `.env` и папку `data` перенести) |
| Сделать копию базы сейчас | `docker compose run --rm backup python scripts/backup_db.py` |

**Где лежат данные.** Всё в папке `data` проекта: `bot.sqlite3` — анкеты, решения кураторов, опросы;
`backups` — копии за последние 14 дней. Это персональные данные кандидатов: не выкладывайте их в открытый доступ
и не пересылайте по почте. Раз в месяц полезно скопировать папку `data/backups` на отдельный диск.

**Восстановить из копии.** `docker compose down`, заменить `data/bot.sqlite3` нужным файлом из `data/backups`
(переименовав его в `bot.sqlite3`), `docker compose up -d`.

## 7. Что можно настроить без программиста

Все правила оценки — в файле `config/rubric.yaml`. После правки — `docker compose restart`.

- **Веса вопросов** — строки `weight:` у пунктов. Чем больше вес, тем сильнее вопрос влияет на балл.
  Временно менять важность можно и ползунками в дашборде — файл при этом не меняется.
- **Описание программы и направлений** — `program_description`. GigaChat задаёт уточняющие вопросы только про то,
  что здесь написано, поэтому описание должно быть точным.
- **Музейные сообщества** для анализа страницы ВК — `vk_analysis.museum_groups`.
- **Опрос волонтёров** — `checkin_survey`: через сколько дней после решения «Взят в команду» он приходит
  и кого считать успешным волонтёром.

## 8. Если что-то не так

| Что видно | Что сделать |
|---|---|
| Бот не отвечает в личных сообщениях | `docker compose logs bot`. Проверьте шаг 2: сообщения и «Возможности ботов» включены, Long Poll включён. Запустите `check_setup.py` |
| В логе `GigaChat не отвечает` или `HTTP 401` | Ключ GigaChat неверный или закончился бесплатный лимит — проверьте в личном кабинете developers.sber.ru |
| Бот отвечает, но без уточняющих вопросов | Не задан или не работает ключ GigaChat: бот перешёл на правила. `check_setup.py` покажет причину |
| Карточки не приходят кураторам | Не задан `VK_CURATOR_PEER_ID` или сообщество удалили из беседы. Напишите в беседе `/id` |
| Дашборд не открывается | `docker compose ps` — у `dashboard` должно быть `healthy`. Порт 8501 может быть занят другой программой |
| После правки rubric.yaml бот не запускается | В файле ошибка отступов. `docker compose logs bot` покажет строку; верните прежнюю версию файла |

Опросы, рассылка и дообучение модели работают сами. Сигналы о недовольных волонтёрах приходят в беседу кураторов,
история версий модели — в дашборде, раздел «Волонтёры».
